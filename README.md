# 原稿棚 ― 短編小説公開サイト

GitHub Pagesでの公開を想定した、静的な小説公開サイトです。ビルド不要（HTML/CSS/JSのみ）。

## ファイル構成

```
index.html          一覧ページ（並び替え・20件ごとのページネーション）
novel.html          個別の小説ページ（?id=xxx で表示する作品を切り替え）
tool.html           本文からJSONを生成するツール（作者用・非公開リンク）
css/style.css       共通スタイル
js/list.js          一覧ページのロジック
js/novel.js         個別ページのロジック
js/tool.js          変換ツールのロジック
data/novels.json    一覧用データ（タイトル・公開日・文字数のみ）
data/novels/*.json  作品ごとの詳細データ（本文・お題など）
```

サンプルとして2作品分のデータ（`夕立の図書室`・`秋の手紙`）を入れてあります。動作確認用なので、公開前に削除してください。

## 作者ページへのリンクの変更

`index.html` と `novel.html` の中に、以下の行があります。`href` を実際のプロフィールサイトのURLに書き換えてください。

```html
<a class="author-link" href="https://example.com/author/" target="_blank" rel="noopener">作者について</a>
```

## ローカルで確認する方法

`fetch()` でJSONを読み込んでいるため、`file://` で直接HTMLを開くとブラウザのセキュリティ制限で読み込みに失敗します。簡易サーバーを立てて確認してください。

```bash
# このフォルダで実行
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## GitHub Pagesへの公開

1. このフォルダの中身をリポジトリのルート（または `/docs` フォルダ）にpush
2. リポジトリの Settings → Pages で公開元のブランチ／フォルダを指定
3. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で公開されます

## 新しい小説を追加する手順

1. `tool.html` をローカルサーバー経由で開く
2. タイトル・ID（半角英数字とハイフン、ファイル名になります）・作成日／公開日／修正日を入力
3. 三題噺の場合は「お題1〜3」に入力（不要なら空欄でOK。個別ページの「お題を表示」ボタンが自動的に出なくなります）
4. 本文を貼り付けて「検証して変換する」を押す
   - かっこ等（「『（(など）で始まらない行の行頭に全角スペースの字下げがない場合、警告が出ます
   - 半角の英数字が混ざっている行にも警告が出ます（誤検知の場合は無視して構いません）
   - 警告があっても変換・ダウンロードは可能です
5. 「詳細データ」欄のJSONを `data/novels/{ID}.json` として保存
6. 「一覧用スニペット」をコピーし、`data/novels.json` の配列に追記（末尾のオブジェクトのあとにカンマを忘れずに）
7. コミットしてpush

## データ形式

### `data/novels.json`（一覧用・配列）

```json
[
  { "id": "yudachi-no-toshokan", "title": "夕立の図書室", "publishedDate": "2026-06-10", "length": 287 }
]
```

### `data/novels/{id}.json`（個別詳細）

```json
{
  "id": "yudachi-no-toshokan",
  "title": "夕立の図書室",
  "createdDate": "2026-06-02",
  "publishedDate": "2026-06-10",
  "modifiedDate": "2026-06-11",
  "themes": ["図書室", "夕立", "傘"],
  "length": 287,
  "body": ["　放課後の図書室には、雨の匂いがこもっていた。", "「傘、忘れたの？」", "..."]
}
```

- `body` は「1行＝1段落」の配列です。ツールが自動的に生成しますが、手で編集する場合も同じ形式にしてください。
- `themes` を省略、または空配列にすると、個別ページに「お題を表示」ボタンは表示されません。
- `length` は文字数（改行を除く全文字数）で、一覧の並び替えにそのまま使われます。手動で編集した場合は数値もあわせて更新してください。

## デザインについて

- ネオブルータリズム寄り：太い枠線・オフセットした影・角丸なし
- 配色：紙のような白ベース＋紺／茶、赤・青・黄をスタンプ的に使用
- 見出し帯の背景に、400字詰め原稿用紙の方眼をごく薄く使用
- 文字数は「◯◯字（約◯◯枚）」の形で、原稿用紙換算（400字＝1枚）も併記
