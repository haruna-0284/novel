# 原稿棚 ― 短編小説公開サイト

GitHub Pagesでの公開を想定した、静的な小説公開サイトです。ビルド不要（HTML/CSS/JSのみ）。

## ファイル構成

```
index.html          一覧ページ（並び替え・20件ごとのページネーション）
novel.html          個別の小説ページ（?id=xxx で表示する作品を切り替え）
tool.html           本文からJSONを生成するツール（作者用・非公開リンク）
css/style.css       共通スタイル
js/list.js          一覧ページのロジック
js/novel.js         個別ページのロジック
js/tool.js          変換ツールのロジック
data/novels.json    一覧用データ（タイトル・公開日・文字数のみ）
data/novels/*.json  作品ごとの詳細データ（本文・お題など）
```
## 作者ページへのリンクの変更

`index.html` と `novel.html` の中に、以下の行があります。`href` を実際のプロフィールサイトのURLに書き換えてください。

```html
<a class="author-link" href="https://example.com/author/" target="_blank" rel="noopener">作者について</a>
```

## ローカルで確認する方法

`fetch()` でJSONを読み込んでいるため、`file://` で直接HTMLを開くとブラウザのセキュリティ制限で読み込みに失敗します。簡易サーバーを立てて確認してください。

```bash
# このフォルダで実行
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## GitHub Pagesへの公開

1. このフォルダの中身をリポジトリのルート（または `/docs` フォルダ）にpush
2. リポジトリの Settings → Pages で公開元のブランチ／フォルダを指定
3. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で公開されます

## 新しい小説を追加する手順

1. `tool.html` をローカルサーバー経由で開く
2. 「種別」を選ぶ（下記「ワンドロ版について」を参照。通常の作品なら「通常」のまま）
3. タイトル・ID（連番の数字を入力すると `novel-01` のような形式に自動変換されます）・作成日／公開日／修正日を入力
4. 三題噺の場合は「お題」欄に「流れ星・図書館・約束」のように「・」区切りでまとめて入力（不要なら空欄でOK。個別ページの「お題を表示」ボタンが自動的に出なくなります）
5. 本文を貼り付けて「検証して変換する」を押す
   - かっこ等（「『（(など）で始まらない行の行頭に全角スペースの字下げがない場合、警告が出ます
   - 半角の英数字が混ざっている行にも警告が出ます（誤検知の場合は無視して構いません）
   - 警告があっても変換・ダウンロードは可能です
6. 「詳細データ」欄のJSONを `data/novels/{ID}.json` として保存
7. 「一覧用スニペット」が表示されていれば、コピーして `data/novels.json` の配列に追記（末尾のオブジェクトのあとにカンマを忘れずに）。種別が「ワンドロ版（修正版とペア）」の場合はスニペットが出ません（一覧には追加しないでください）
8. コミットしてpush

## ワンドロ版について

1時間の時間制限で書いた「ワンドロ版」と、あとから加筆修正した完成版をセットで公開できます。ツールの「種別」で使い分けます。

| 種別 | 使いどころ | ID | 一覧への表示 |
|---|---|---|---|
| 通常 | ワンドロと無関係な作品 | `novel-XX` | 通常表示 |
| 修正版（ワンドロ版あり） | 加筆修正した完成版（ペアあり） | `novel-XX` | 表示（青枠＋「ワンドロ版あり」バッジ） |
| ワンドロ版のみ | 完成版を作らない・ワンドロ版だけ公開 | `novel-XX` | 表示（赤枠＋「ワンドロ版のみ」バッジ） |
| ワンドロ版（修正版とペア） | 「修正版（ワンドロ版あり）」と対になる生の1時間版 | `novel-XXw`（自動） | 表示されない（修正版ページからのみリンク） |

「修正版（ワンドロ版あり）」と「ワンドロ版（修正版とペア）」は、**同じ連番**を入力してください（例：修正版が `novel-05` なら、ペアのワンドロ版のIDは自動的に `novel-05w` になります）。個別ページ側で、修正版からワンドロ版へ・ワンドロ版から修正版へ、相互にリンクするボタンが自動的に表示されます。

一覧ページの並び替えバーには「ワンドロ版あり」「ワンドロ版のみ」の絞り込みボタンがあります（同時に選択可能・OR条件）。

## データ形式

### `data/novels.json`（一覧用・配列）

```json
[
  { "id": "yudachi-no-toshokan", "title": "夕立の図書室", "publishedDate": "2026-06-10", "length": 292 },
  { "id": "novel-05", "title": "夜空の騎士", "publishedDate": "2026-07-10", "length": 168, "wandoroId": "novel-05w" },
  { "id": "novel-09", "title": "とある一時間の物語", "publishedDate": "2026-07-15", "length": 105, "isWandoroOnly": true }
]
```

- `wandoroId` を持つエントリは、修正版として一覧に表示されます（青枠）。対になるワンドロ版（`novel-05w`）は一覧には表示されません。
- `isWandoroOnly: true` のエントリは、ワンドロ版そのものが一覧の表示対象です（赤枠）。

### `data/novels/{id}.json`（個別詳細）

```json
{
  "id": "yudachi-no-toshokan",
  "title": "夕立の図書室",
  "createdDate": "2026-06-02",
  "publishedDate": "2026-06-10",
  "modifiedDate": "2026-06-11",
  "themes": ["図書室", "夕立", "傘"],
  "length": 292,
  "body": ["# 一　雨宿り", "　放課後の図書室には、雨の匂いがこもっていた。", "「傘、忘れたの？」", "..."]
}
```

ワンドロ機能に関する追加フィールド（すべて任意）：

```json
{ "wandoroId": "novel-05w" }   // 修正版側：対になるワンドロ版のID
{ "isWandoro": true, "revisedId": "novel-05" }  // ワンドロ版側：修正版がある場合はIDも入れる
{ "isWandoro": true }          // ワンドロ版のみの場合：revisedIdは省略
```

- `body` は「1行＝1段落」の配列です。ツールが自動的に生成しますが、手で編集する場合も同じ形式にしてください。
- 章タイトルにしたい行は、先頭に `# `（半角シャープ＋半角スペース）を付けてください（例：`"# 第一章　夜明け"`）。個別ページでは大きな見出しとして表示され、字下げチェックの対象外・文字数にもカウントされません。
- `themes` を省略、または空配列にすると、個別ページに「お題を表示」ボタンは表示されません。
- `length` は文字数（改行を除く全文字数）で、一覧の並び替えにそのまま使われます。手動で編集した場合は数値もあわせて更新してください。

## デザインについて

- ネオブルータリズム寄り：太い枠線・オフセットした影・角丸なし
- 配色：紙のような白ベース＋紺／茶、赤・青・黄・緑をスタンプ的に使用
- 文字数は赤枠のスタンプ風に、斜めに配置して表示
